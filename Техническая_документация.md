## 1. Описание продукта

**«ДермаСкрин»** — веб-приложение для первичной (предварительной) оценки риска
кожных новообразований по одной фотографии. Пользователь загружает фото родинки,
а программа оценивает визуальное сходство с опасными образованиями (меланома,
базалиома, актинический кератоз) и выдаёт:

- цветовую индикацию риска (🟢 зелёный / 🟡 жёлтый / 🔴 красный);
- числовой «риск-скор» от 0 до 100;
- рекомендацию (наблюдать или обратиться к дерматологу);
- памятку самопроверки **ABCDE**;
- обязательный медицинский дисклеймер.

> ⚠️ Программа **не ставит диагноз** и не является медицинским изделием — она лишь
> оценивает визуальное сходство и мотивирует обратиться к врачу.

## 2. Архитектура: схема «клиент — сервер»

Система построена по классической схеме «клиент–сервер».

| Роль | Что это | В нашем проекте |
|---|---|---|
| **Клиент** | Программа, которая отправляет запросы | Браузер (Chrome, Edge и т.п.) |
| **Сервер** | Программа, которая принимает запросы и отвечает | `app.py` на Python + Flask |

Обмен идёт по протоколу **HTTP** — тому же, что использует любой сайт в интернете.

---

## 3. Что такое «сервер» простыми словами

В этом проекте **сервер — это не отдельный компьютер и не сайт в интернете, а обычная
программа, запущенная на том же компьютере**. Она:

1. запускается командой `python app.py`;
2. загружает обученную нейросеть в оперативную память;
3. начинает «слушать» порт **5000** (порт — номер «окна», через которое приходят запросы);
4. на каждый запрос отвечает HTML-страницей.

**Адреса и порты:**
- `127.0.0.1` (он же `localhost`) — «этот же компьютер», доступно только локально.
- `0.0.0.0` — «слушать все сетевые интерфейсы», поэтому сайт доступен и по IP компьютера
  в локальной сети (например, `192.168.1.43`).
- Порт `5000` — номер «окна», выбранный для нашего приложения.

**Важно для понимания:** это *локальный* сервер. Чтобы сайт был доступен всем в интернете,
нужен хостинг (VPS/облако) и публичный IP-адрес. Для защиты проекта локального запуска
достаточно — всё можно показать прямо на ноутбуке.

## 4. Путь фотографии от загрузки до результата

1. Браузер запрашивает главную страницу (`GET /`) → сервер отдаёт `index.html`.
2. Пользователь выбирает фото и жмёт «Анализировать» → браузер отправляет файл на сервер
   (`POST /predict`).
3. Сервер обрабатывает фото:
   - уменьшает изображение до размера **224×224** пикселей;
   - приводит значения пикселей к диапазону **[-1, 1]** (нормализация под MobileNetV2);
   - подаёт массив пикселей в **нейросеть**;
   - получает вероятность «высокого риска» (число от 0 до 1);
   - переводит её в **«риск-скор»** (процентильный ранг 0–100 относительно валидационной выборки);
   - выбирает **цветовую зону** (зелёный/жёлтый/красный).
4. Сервер формирует страницу `result.html` (результат + ABCDE + дисклеймер) и отправляет браузеру.
5. Пользователь видит результат.

## 5. Компоненты системы

| Компонент | Что делает | Технология |
|---|---|---|
| **Данные** | 10 015 дерматоскопических снимков + разметка | HAM10000 (CSV + JPEG) |
| **Модель** | Бинарная классификация «низкий/высокий риск» | TensorFlow/Keras, MobileNetV2 (transfer learning) |
| **Веб-приложение** | Приём фото, вывод результата | Flask (Python) |
| **Интерфейс** | Страницы загрузки и результата | HTML + CSS (Jinja2-шаблоны) |

## 6. Стек технологий

- **Python 3.12** — основной язык.
- **TensorFlow 2.21 / Keras 3** — обучение и запуск нейросети.
- **scikit-learn** — разбиение данных, метрики качества.
- **pandas, matplotlib** — анализ данных (EDA) и визуализации.
- **Flask** — веб-сервер.
- **Pillow** — обработка изображений.

## 8. Как запустить

```powershell
# один раз: установить зависимости
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt

# запустить сайт (нужны model/skin_model.keras и model/config.json)
venv\Scripts\python.exe app.py
```

Затем открыть в браузере **http://127.0.0.1:5000**.

## 9. Метрики модели (учебный прототип)

| Метрика | Значение |
|---|---|
| **ROC-AUC** | ≈ 0.65 |
| Recall «высокий риск» | ≈ 0.59 |
| Precision «высокий риск» | ≈ 0.29 |
| Accuracy | ≈ 0.63 |

> ⚠️ Модель обучена на **CPU** за ограниченное число эпох, поэтому качество скромное.
> Это демонстрация полного пайплайна (данные → обучение → веб), а не медицинский инструмент.

## 10. Ограничения (честные, для защиты)

1. **Сдвиг домена:** датасет снят дерматоскопом, а пользователь снимает смартфоном —
   на «обычных» фото качество может быть ниже.
2. **Дисбаланс классов:** невусов (`nv`) примерно в 6 раз больше, чем меланом (`mel`).
3. **Ограниченные вычислительные ресурсы:** обучение шло на CPU без GPU.

## 11. Словарь терминов

- **Сервер** — программа, которая принимает запросы и возвращает ответы.
- **Клиент** — программа, которая отправляет запросы (у нас — браузер).
- **Порт** — номер «окна», по которому сервер принимает запросы (у нас 5000).
- **HTTP** — протокол обмена данными между клиентом и сервером.
- **GET / POST** — типы HTTP-запросов: получить страницу / отправить данные.
- **Нейросеть** — математическая модель, обучающаяся на примерах.
- **Transfer learning** — использование сети, предобученной на ImageNet, и дообучение
  её на своей задаче.
- **ROC-AUC** — метрика качества ранжирования: 0.5 — случайно, 1.0 — идеально.
- **Риск-скор** — число 0–100, показывающее, насколько фото «подозрительнее» эталонных снимков.
