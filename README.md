# 🤖 ДермаСкрин — умный помощник для первичной оценки риска кожных новообразований

Учебный проект по информатике/ИИ. Нейросеть по фотографии родинки оценивает
степень визуального сходства с опасными образованиями (меланома, базалиома,
актинический кератоз) и выдаёт рекомендацию + памятку самопроверки ABCDE.

> ⚠️ **ВАЖНО.** Это НЕ медицинский прибор и НЕ диагноз. Программа лишь оценивает
> визуальное сходство и не заменяет консультацию врача-дерматолога.

## Данные

- **HAM10000** — 10 015 дерматоскопических снимков, 7 классов (`dx`).
- Бинарная разметка: `mel, bcc, akiec` → **высокий риск**, `nv, bkl, df, vasc` → **низкий риск**.
- Источник изображений: зеркало Hugging Face
  [`ShiroOnigami23/skin-cancer-ham10000-dataset`](https://huggingface.co/datasets/ShiroOnigami23/skin-cancer-ham10000-dataset).

## Структура проекта

```
Родинки/
├── app.py               # Flask-приложение (веб-интерфейс)
├── train.py             # обучение нейросети
├── eda_local.py         # локальный EDA (графики для отчёта)
├── download_data.py     # скачивание изображений с Hugging Face
├── requirements.txt
├── data/
│   ├── HAM10000_metadata.csv   # разметка
│   └── images/                 # ISIC_*.jpg (10 015 шт.)
├── model/
│   ├── skin_model.keras        # обученная модель
│   └── config.json             # порог, зоны риска, метрики
├── templates/           # HTML-страницы
└── static/              # CSS
```

## Установка

```powershell
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Скачивание данных

```powershell
python download_data.py          # качает изображения в data/ham10000/
# затем раскладываем в data/images/ (см. ниже)
```

## Обучение

```powershell
venv\Scripts\python.exe train.py
```

На выходе: `model/skin_model.keras` и `model/config.json` (порог, метрики, зоны риска).

## Запуск веб-приложения

```powershell
venv\Scripts\python.exe app.py
```

Откройте в браузере **http://127.0.0.1:5000**, загрузите фото родинки и получите
результат с цветовой индикацией риска, памяткой ABCDE и дисклеймером.

## Метрики модели (учебный прототип)

- **ROC-AUC (test) ≈ 0.65**
- Полнота (recall) по классу «высокий риск» ≈ 0.59, точность (precision) ≈ 0.29
- Accuracy ≈ 0.63
- Порог решения и зоны риска — в `model/config.json`

> ⚠️ Модель обучена на CPU за ограниченное число эпох, поэтому её качество
> скромное. Это демонстрация полного пайплайна (данные → обучение → веб),
> а НЕ медицинский инструмент.
